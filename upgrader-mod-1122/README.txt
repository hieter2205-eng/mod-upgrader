Мод "Апгрейдер" для Minecraft 1.12.2 (Forge). Один файл JAR, больше ничего не нужно.

ПОЛУЧИТЬ JAR БЕЗ УСТАНОВКИ ПРОГРАММ:
 1. Создай репозиторий на github.com и залей туда ВСЁ содержимое этой папки (включая скрытую папку .github).
 2. Вкладка Actions -> build -> дождись зелёной галочки -> внизу Artifacts -> upgrader-jar.
 3. Распакуй скачанный zip -> внутри upgrader-1.0.0.jar.

УСТАНОВКА: положи jar в %appdata%\.minecraft\mods и запусти Forge 1.12.2 в TLauncher.
БЛОК: творческое меню, вкладка "Разное", либо /give @p upgrader:upgrader
КРАФТ: пурпурный блок по углам, железо по бокам, алмаз в центре.
